# HTML Interview Questions & Answers

Q) HTML mhanje kay?
Ans: HTML (HyperText Markup Language) hi web pages chi structure banvnyasathi vaparleli markup language aahe. Ti elements/tags vaprun content (text, image, link) define karte.

Q) HTML5 madhe navin kay aale?
Ans: Semantic tags (header, footer, section, article, nav), audio/video tags, canvas, localStorage/sessionStorage, form che navin input types (email, date, range), geolocation API.

Q) DOCTYPE mhanje kay ani te kashasathi lagte?
Ans: `<!DOCTYPE html>` browser la sangte ki page HTML5 aahe. Te nasel tar browser quirks mode madhe jato ani rendering vegli disu shakte.

Q) HTML tag, element ani attribute madhla farak?
Ans: Tag mhanje `<p>`. Element mhanje opening tag + content + closing tag (`<p>Hello</p>`). Attribute mhanje tag madhe extra info (`class="box"`, `id="main"`).

Q) Block-level ani inline elements madhla farak?
Ans: Block elements navin line var suru hotat ani purna width ghetat (div, p, h1, section). Inline elements same line madhe rahtat ani fakt content eva width ghetat (span, a, strong).

Q) Semantic HTML mhanje kay? Fayde kay?
Ans: Meaning asleli tags vaprane (header, nav, main, article, footer). Fayde: SEO changla hoto, accessibility sudharte, code vachayla sopa hoto.

Q) `<div>` ani `<span>` madhla farak?
Ans: `div` block-level container aahe (layout sathi). `span` inline container aahe (text cha ek bhag style karnyasathi).

Q) `id` ani `class` madhla farak?
Ans: `id` unique asto, ek page var ek id fakt ek element la. `class` anek elements la deta yete ani ek element la anek classes pan deta yetat.

Q) `<a>` tag cha vapar kasa kartat? `target="_blank"` kay karte?
Ans: `<a href="url">Link</a>` ne link banavtat. `target="_blank"` link navin tab madhe ughadte. Security sathi `rel="noopener noreferrer"` jodave.

Q) Image kashi takayachi? `alt` attribute ka important aahe?
Ans: `<img src="a.jpg" alt="description">`. `alt` image load na jhalyas dakhavla jato, screen readers vaprtat ani SEO sathi pan upayogi aahe.

Q) Absolute ani relative path madhla farak?
Ans: Absolute path madhe purna URL asto (`https://site.com/a.png`). Relative path current file chya sapekshat asto (`./images/a.png`).

Q) Ordered, unordered ani description list mhanje kay?
Ans: `<ol>` numbered list, `<ul>` bullet list, `<dl>` madhe term (`<dt>`) ani description (`<dd>`) jodya astat.

Q) HTML table kashi banvtat? Mukhya tags konte?
Ans: `<table>`, `<thead>`, `<tbody>`, `<tfoot>`, `<tr>` (row), `<th>` (heading cell), `<td>` (data cell). Merge sathi `colspan` ani `rowspan`.

Q) `colspan` ani `rowspan` mhanje kay?
Ans: `colspan` ek cell kitya columns madhe pasaral te theravto. `rowspan` kitya rows madhe pasaral te theravto.

Q) HTML form mhanje kay? `action` ani `method` kay aahet?
Ans: Form user kadun data ghenyasathi vaparla jato. `action` data kuthe pathvaycha (URL), `method` kasa pathvaycha (GET kiwa POST).

Q) GET ani POST madhla farak?
Ans: GET data URL madhe pathavto (visible, limited size, bookmark hou shakto). POST data request body madhe pathavto (hidden, jast size, sensitive data sathi changla).

Q) `<input>` che mukhya types konte?
Ans: text, password, email, number, checkbox, radio, file, date, range, color, submit, reset, hidden.

Q) `<label>` ka vaprtat? `for` attribute kay karto?
Ans: Label input shi jodte. `for` chi value input chya `id` shi match jhali ki label var click kelyas input focus hoto. Accessibility sathi important.

Q) `placeholder` ani `value` madhla farak?
Ans: `placeholder` hint text aahe, user type kelyavar jato. `value` input cha actual default data aahe.

Q) `required`, `disabled`, `readonly` madhla farak?
Ans: `required` bharlyashivay submit hot nahi. `disabled` input vaparu shakat nahi ani submit pan hot nahi. `readonly` vachta yeto pan edit hot nahi, submit hoto.

Q) Checkbox ani radio button madhla farak?
Ans: Checkbox madhe anek options select karta yetat. Radio madhe same `name` chya group madhun fakt ek option select hoto.

Q) `<select>` ani `<option>` kasa vaprtat?
Ans: `<select>` dropdown banavto, `<option>` madhe choices astat. `multiple` attribute ne anek select karta yetat.

Q) `<textarea>` kashasathi?
Ans: Multi-line text input sathi. `rows` ani `cols` ne size theravta yete.

Q) `<button>` ani `<input type="submit">` madhla farak?
Ans: `<button>` madhe HTML content (icon, image) takta yeto. `input type="submit"` fakt text value dakhavto. Button chi default type submit aahe.

Q) `<iframe>` mhanje kay?
Ans: Current page madhe dusra web page embed karnyasathi tag. Example: YouTube video, Google Maps.

Q) `<meta>` tag ka vaprtat?
Ans: Page chi metadata dyayla: charset, viewport, description, keywords. Example: `<meta name="viewport" content="width=device-width, initial-scale=1.0">`.

Q) Viewport meta tag cha upyog kay?
Ans: Mobile devices var page chi width ani zoom control karto, mhanje responsive design sathi aavashyak.

Q) `<head>` ani `<body>` madhe kay astat?
Ans: `<head>` madhe title, meta, link, style, script (page info). `<body>` madhe user la distnara content.

Q) `<script>` madhe `async` ani `defer` madhla farak?
Ans: `async` script download hotana HTML parsing chalu theve ani download zalyavar lagech run hote (order guarantee nahi). `defer` HTML parse zalyavar, order madhe run hote.

Q) `<link>` tag cha upyog?
Ans: External resources jodayla, mostly CSS: `<link rel="stylesheet" href="style.css">`. Favicon sathi pan vaprtat.

Q) Inline, internal ani external CSS madhla farak?
Ans: Inline: tag madhe `style=""`. Internal: `<style>` tag madhe. External: vegla `.css` file `<link>` ne. External best practice aahe.

Q) `<strong>` ani `<b>` madhla farak?
Ans: Doghe bold dakhavtat, pan `<strong>` meaning (important) deto, semantic aahe. `<b>` fakt visual style.

Q) `<em>` ani `<i>` madhla farak?
Ans: `<em>` emphasis cha semantic meaning deto. `<i>` fakt italic look deto.

Q) `<section>`, `<article>`, `<aside>` kashasathi?
Ans: `section` related content cha group. `article` independent content (blog post). `aside` side content (sidebar, ads).

Q) `<figure>` ani `<figcaption>` kay aahet?
Ans: `figure` madhe image/diagram ani tyacha `figcaption` (caption) grouped astat.

Q) HTML entities mhanje kay?
Ans: Special characters lihnyachi pad: `&lt;` (<), `&gt;` (>), `&amp;` (&), `&nbsp;` (non-breaking space), `&copy;` (©).

Q) Void (self-closing) elements konte?
Ans: Closing tag nasleli elements: `<br>`, `<hr>`, `<img>`, `<input>`, `<meta>`, `<link>`.

Q) `<audio>` ani `<video>` kasa vaprtat?
Ans: `<video controls src="a.mp4"></video>`. Attributes: controls, autoplay, loop, muted, poster. Audio pan same prakare.

Q) `localStorage`, `sessionStorage` ani cookies madhla farak?
Ans: localStorage: browser band zala tari data rahto (~5MB). sessionStorage: tab band zala ki data jato. Cookies: chhote (~4KB) ani har request sobat server la jatat.

Q) `data-*` attributes mhanje kay?
Ans: Custom data store karnyasathi attributes, example `data-id="5"`. JS madhe `element.dataset.id` ne milto.

Q) `contenteditable` kay karto?
Ans: Element user la browser madhe edit karu deto.

Q) Accessibility sathi HTML madhe kay karave?
Ans: Semantic tags vapra, images la alt dya, labels vapra, ARIA attributes (`aria-label`, `role`) vapra, keyboard navigation chalel yachi khatri kara.

Q) `<canvas>` ani `<svg>` madhla farak?
Ans: Canvas pixel-based aahe (JS ne draw), scaling var blur hoto. SVG vector-based XML aahe, scale kela tari sharp rahto ani DOM element astat.

Q) Responsive images kashi kartat?
Ans: `srcset` ani `sizes` attributes kiwa `<picture>` element vaprun, screen size nusar vegli image load hote.

Q) `<br>` ani `<hr>` kay karatat?
Ans: `<br>` line break deto. `<hr>` horizontal line (thematic break) deto.

Q) `<pre>` ani `<code>` tag kashasathi?
Ans: `<pre>` spaces ani line breaks jase aahet tase dakhavto. `<code>` code snippet mark karto. Donhi ekatra vaprtat.

Q) `<abbr>` ani `<mark>` kay aahet?
Ans: `<abbr title="...">` abbreviation cha full form tooltip madhe dakhavto. `<mark>` text highlight karto.

Q) `<noscript>` kay karto?
Ans: Browser madhe JavaScript disabled aslyas dakhavaycha content tyat takta yeto.

Q) HTML madhe comments kase lihayche?
Ans: `<!-- he comment aahe -->`. Browser te dakhvat nahi.

Q) `<base>` tag cha upyog?
Ans: Page madhlya sarva relative URLs sathi base URL set karto: `<base href="https://site.com/">`.

Q) `title` attribute ani `<title>` tag madhla farak?
Ans: `<title>` browser tab cha ani SEO cha page title aahe (head madhe). `title` attribute kontyahi element var hover kelyavar tooltip dakhavto.

Q) HTML SEO sathi kay best practices?
Ans: Ek `<h1>` per page, semantic tags, meaningful title ani meta description, image alt, clean URLs, fast loading, mobile-friendly.

Q) Heading tags cha kram kasa aahe?
Ans: `<h1>` te `<h6>`. `h1` sarvat mothe ani important, `h6` sarvat lahan. Level skip karu naye (h1 nantar thet h4 nako).
